# ARM · 学习看板

> 作者：hehaifeng  
> 学习周期：2026年7月 — 至今

## 文件说明

| 文件 | 说明 |
|------|------|
| `learning-dashboard.html` | 学习看板主文件，浏览器直接打开 |
| `learning-plan.md` | 会员模块 & 销售模块学习计划 |
| `member-progress.md` | 学习进度跟踪 |
| `会员档案模块-学习成果.md` | 会员档案模块业务学习成果总结 |

## 使用方式

1. 下载 `learning-dashboard.html`
2. 双击用浏览器打开
3. 左侧大纲筛选模块，右侧查看详情

## 数据更新

编辑 `learning-dashboard.html` 中的 `MODULES` 数组添加模块，`achievementMonths` 数组添加月度成果。
